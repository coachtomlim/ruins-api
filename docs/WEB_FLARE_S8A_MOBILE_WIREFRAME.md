# WEB-FLARE S8A Mobile Wireframe

These are structural wireframes, not final visual art.

## 1. Invitation

```text
┌─────────────────────────────┐
│        DUNGEON RUNNER       │
│                             │
│      [animated Hero]        │
│                             │
│ Your friend TOM challenged  │
│ you to choose a dungeon.    │
│                             │
│      Takes ~30 seconds      │
│                             │
│ [     ACCEPT CHALLENGE    ] │
└─────────────────────────────┘
```
