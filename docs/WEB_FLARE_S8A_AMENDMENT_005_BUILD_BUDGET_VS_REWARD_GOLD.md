# WEB-FLARE S8A Amendment 005: Dungeon Budget vs Reward Gold

This amendment clarifies two different game resources.

## Dungeon construction resource

The fixed 100-point allowance used to choose monsters, traps and supports is a **Dungeon Budget**.

Receiver-facing label:

`DUNGEON BUDGET [USED] / 100`

It resets for each setup and is not deducted from any saved player reward.

## Post-run reward

Post-run `GOLD` is the earned player reward shown on the dedicated reward screen.

- friend Hero Gold belongs to the sender/friend side;
- Dungeon Builder Gold belongs to the receiver side.

## UX requirement

Do not make a first-time player think that selecting a 30-cost monster spends 30 of their earned Gold.

The phone UI must distinguish construction budget from reward Gold through labels and placement without requiring a help page.

Do not change accepted monster/trap/support costs or the 100-point budget balance in S8A.
