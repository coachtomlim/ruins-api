# WEB-FLARE S8B Owner Decision Packet 001

Status: partially superseded by later Owner decisions.

## Locked decisions

- Gold is used to improve the player's own Hero-Runner.
- Starter Runner uses individual item bonuses, not hidden baked gear bonuses.
- Starter equipment: Wooden Club in `WEAPON` (+4 ATK) and Wooden Shield in `SHIELD` (+1 DEF).
- No starter armor set.
- Armor progression is piece-by-piece: `HEAD`, `CHEST`, `HANDS`, `LEGS`, `FEET`.
- Monsters that own/equip governed items receive those item stat modifiers through the same effective-stat composition rule.

`docs/WEB_FLARE_S8B_STARTER_LOADOUT_AUTHORITY.md`
