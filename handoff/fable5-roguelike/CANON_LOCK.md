# Canon Lock

This handoff is for Fiends & Hero Roguelike Beta implementation in a new repository.

Do not rewrite Alpha canon.

The 10-room Forgotten Ruin of the Dark Galan is Content Module 001.

Preserve:

- room names
- exits
- one-way movement rules
- fiends
- artifacts
- scrolls
- dialogue
- journals
- combat rules
- boss rules
- inventory rules
- win/loss logic
- known canon conflicts

Resolve canon conflicts only when explicitly instructed by Thomas.

The legacy `ruins-api` repository remains the canon/reference source. The new `fiends-hero-roguelike` repository should import, structure, validate, and play the canon; it should not silently revise it.
