S2 UX direction

- Builder is a four-screen, no-page-scroll flow: Room, Encounter, Prediction, Send.
- Room selection is a single large stock-Flare preview with left/right arrows, keyboard ArrowLeft/ArrowRight, and swipe support.
- Persistent bottom navigation moves between screens; state is retained when moving back.
- Encounter screen adds quick presets plus individual guard/potion controls under the existing 100-gold rule.
- Send screen auto-builds the deterministic challenge and supports native Web Share, copy fallback, and player preview.
- The player runtime remains separate and unchanged by this UI pass.
